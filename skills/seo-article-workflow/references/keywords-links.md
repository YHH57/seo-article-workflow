# 关键词、来源与链接

## 关键词计划

围绕阅读任务确定主词，保存来源和理由。研究查询、最终主词、辅助表达及专业术语分开，不逐字复制搜索词。

标准模式配置为一个主词、3–5 个辅助表达；其他模式按本篇计划安排，不自动继承数量。H1 自然使用主词或准确变体，引言点明主题，子标题表达对应内容。FAQ 和结论以回答和收拢为先，不设密度、重复次数或强制插词。

记录完整词组出现次数、自然变体和实际覆盖主题。完整词组 0 次是文字统计，不是搜索量为 0，也不能声称该词已逐字插入。

## 链接计划

先区分 external_article 与 owned_blog，再按单篇目标和平台决定数量。链接在需要进一步了解的位置提供相关补充，锚文本准确描述页面，不把每次关键词出现都加链接。

记录 URL、角色、位置、锚文本、读者用途、读取状态及次数。核查真实可访问且内容匹配；复用已有验证时保留日期，不声称本轮实时检查。无法访问就记录缺口。

自然度检查：读者为何在此需要链接？点击能得到什么？句子是否正常解释内容？主语和动词是否准确描述页面？避免没有信息量的资源介绍句。

独立 URL 与出现次数分开。同一页面正文与文末各一次，是一个 URL、两处链接；技术引用另计。外部文章不自动套用自有博客配额，rel 和最终呈现按真实关系与平台规则，未知留空。

标准模式的自有博客约定：正文 2 处，Related Examples 2–4 条，合计 4–6 处；正文优先不同页面。仅在该配置被采用且发布类型为 owned_blog 时生效。找不到相关页面就报告缺口，不用无关页凑数。

## 来源角色与引用

- `Sources`：实际读过且用于内容的来源，说明支持什么及范围。技术问题优先一手资料；无关权威页不能替代真正依据。
- `Related Examples`：品牌、产品或项目实例，提供补充，不当作独立性能证明。外部文章也可有，数量随计划。
- `Further Reading`：实际读过、有独立补充价值的资料，不重复既有来源，不为填模板加链接。

标准模式将同行产品页与博客仅作内部研究，不进入公开引用；这是该模式采用的编辑策略，不是所有领域的来源禁令。机构或厂商技术指南也不自动称为独立实验。

按采用的模式和平台规范排版。标准模式为 H2 References、必要的 H3 分组、跨组连续编号；每项是加粗标题、完整可点击 URL、Note。该模式正文不用数字脚注；无论模式为何，内部仍保存论点—来源映射。

平台未知不声称满足平台要求。平台研究仅在需要时核对官方规则和入口，历史样文仅为线索；最终链接属性、canonical、收录和排名不作保证。
