# 查询、复用与证据

## 查询前给方案

说明本轮要解决的决定，展示完整搜索词或直接读取 URL、目的、工具/供应商、引擎、地区、语言、设备、日期及其他过滤、请求深度、计划阅读范围。不支持或不可确认的条件留 `null`，不把聚合搜索声称为指定引擎与市场的结果。

- **意图验证查询**：观察页面类型、内容重点和范围，用于选方向。
- **内容研究查询**：核对准备解释的事实、机制、例子和条件，用于正文。

读取已知来源、复用缓存不叫新增关键词搜索。调整查询时先说明新增方案。付费前说明必要性、计划用量和可知成本，按工具与用户授权执行；实际费用未返回则未知。收藏、跟踪、订阅和一次查询分开处理。

## 优先复用

顺序为当前记录 → 同站研究/关键词资产 → 已连接工具历史 → 必要的新查询。检查确切查询、引擎/供应商、位置范围、语言、设备、指标周期、时间及用途。

全国数据不等于某城市；宽泛词指标不转给长尾词；广告竞争不是自然 KD；搜索量不是 AI 提问量。不匹配资料可作有标记的背景，不能记为已完成对应验证。

年龄只是适用性因素。由决策缺口、环境变化、矛盾或用户刷新要求触发重查；改语气、格式或未改变主题的段落通常不刷新关键词。

## 结果与状态

按 [query-record.template.json](../assets/query-record.template.json) 记录实际调用。状态为 `planned/running/completed/partial/failed/skipped/reused`。

指标各自记录 `not_queried/failed/empty/available` 和值；前三者值为 null。真实 0 仅在 available 且有原始返回时使用。成功但无数据，不等于没有需求。

保留响应或快照、请求条件、实际条数、去重方式、读到的 URL 和范围。多个调用合并时注明，不能称为一次搜索的前十。编辑输入的查询词仍是编辑推导；工具真正新增返回的词才标为工具发现。

每轮写出：**原假设 → 结果依据 → 保留/调整/放弃及理由**。不足以判断可保留待验证；失败记录错误和影响，成功重试也保留先前失败。

## 证据边界

为重要论点记录性质及支持范围，不要求每句话独立公开引用：

| 性质 | 处理 |
|---|---|
| 直接来源事实 | 来源、读取位置、适用范围和原始记录 |
| 网站/厂家声明 | 保留自述性质，不作独立测试或行业事实 |
| 稳定基础知识 | 可直接解释，不虚构来源包装常识 |
| 条件明确的推理 | 说明前提，不冒充实测或来源原话 |
| 教学假设 | 自然说明是假设，不虚构真实客户或结果 |
| 未知或冲突 | 指明缺口及影响，收窄、删除或补查 |

冷门、不确定或影响关键判断的主张主动核查；数字、标准、法规、时效信息、具体兼容和性能结论要有相应可靠依据。缺少关键解释时返回有明确问题的研究，不用“咨询对方”或堆资料代替解释。

机构名称不是质量证明；网页标题、标准摘要、搜索片段仅支持实际读到的内容。PDF 记录已读页码；只看摘要不声称核对全文。来源支持机制，不必包含措辞相同的结论句。

研究库与公开引用分开。用 [evidence.template.json](../assets/evidence.template.json) 记录来源、论点、性质、范围、公开角色及限制；按 [keywords-links.md](keywords-links.md) 决定公开链接。
